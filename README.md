# MagniBot

Projeto final da disciplina de Sistemas Embarcados (2026.2): firmware de um braço robótico MagniBot de 5/6 graus de liberdade, controlado por um ESP32-S3 DevKitC-1. O firmware é escrito em C, com ESP-IDF e FreeRTOS, em arquitetura modular, com telemetria e controle por UART/USB Serial, interfaces para servos, sensores, botões e LED RGB e parada de emergência com latch.

## Estrutura

- `firmware/`: código-fonte do firmware, testes, scripts e configuração de build (ESP-IDF).
- `doc/`: documentação e material de acompanhamento do projeto.
